What I've shipped

BIFROST / RAMEAU

A multi-model AI inference platform I designed, built, and operate solo.

  • Three nodes, twelve local routing tiers, a Kubernetes control plane.
  • A complexity classifier routes each request to the smallest model tier that can handle it.
  • LangGraph agents decompose tasks into parallel subtasks and call tools.
  • A tiered verification harness gates every output before it ships: emptiness and refusal checks, stub detection, acceptance-criteria coverage, semantic-embedding drift, and a blocking sandboxed unit-test gate, with an advisory compile check on the assembled result. Only the unit-test gate blocks; a failure there escalates with its evidence attached.

Over a measured 30-day window it moved 33.9 million tokens — a median of about 408,000 a day, peaking at 5.3 million on its busiest day. Local hardware carried 69% of that volume; most of the remainder ran on free-tier provider-hosted models, which held metered inference spend for the entire window to about six cents. It also supports a fully offline routing mode that drops every provider tier, for environments where nothing may leave the building. RAMEAU will be the containerized Apache-2.0 release of that platform, built for on-premises deployment.

How I work

I build with coding agents as my default mode, not as an experiment. Agents are dispatched in parallel, each on its own branch and session, against a codebase I deliberately made agent-ready:

  • A written ruleset derived from real failures
  • A dispatch journal so agent work stays auditable
  • Protected-file conventions
  • Verification gates that run before anything merges

The governance is the interesting part. Running agents is easy. Running them so you can trust what comes out is the actual work.
